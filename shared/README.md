# Shared image inputs

The overlay contains AmogOS desktop defaults, the Amogus launcher icon, numbered
wallpapers and Fastfetch branding. They are tracked here so builds never need
access to the original build machine. Debian-specific boot, firmware and package
configuration lives under amogos-debian/. amogos-arch/ is intentionally reserved.

The project artwork is supplied by AmogOS. The Plasma profile retains its
GPL-2.0-or-later metadata. Application assets and third-party notices remain in
the pinned application source repository and Debian packages. The builder does
not grant additional rights to third-party artwork, fonts or applications.
